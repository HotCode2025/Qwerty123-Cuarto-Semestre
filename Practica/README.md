## Avatar — Combate Elemental

Juego por turnos con personajes de Avatar (Zuko, Katara, Aang y Toph) que también permite crear personajes a mano, al azar o en masa. La clase `Avatar` concentra la POO y el resto del código maneja el DOM y la lógica de combate.

- [public/avatar.html](Avatar/public/avatar.html) — pantallas de selección, creación y combate
- [public/script.js](Avatar/public/script.js) — clase `Avatar`, catálogo y lógica del juego
- [public/crear-personaje.js](Avatar/public/crear-personaje.js) — creación manual, aleatoria y masiva
- [public/style.css](Avatar/public/style.css) — estilos
